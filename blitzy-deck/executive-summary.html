Section 04

Backend Architecture

Weighted matching engine and six report models built on the Odoo 19 ORM with zero Enterprise dependencies.

Matching Engine Flow

Weighted Scoring Across Four Features

Seven-step pipeline from statement line to partial reconcile, with explicit confidence tiers.

statement.line matching.engine move.line reconcile.model partial.reconcile
  1. 1 statement.line→matching.engine score_candidates(line)
  2. 2 matching.engine→move.line fetch candidates within ±90 day window
  3. 3 matching.engineSELF weight amount 0.35 · reference 0.25 · partner 0.25 · date 0.15
  4. 4 matching.engine→reconcile.model apply rule regex + amount bounds
  5. 5 reconcile.model→matching.engineRETURN candidate set + confidence
  6. 6 matching.engine→statement.lineRETURN HIGH ≥ 95.0 (auto) · MEDIUM ≥ 70.0 (review) · LOW ≥ 50.0 (manual)
  7. 7 statement.line→partial.reconcile create partial reconcile (when amounts differ)
