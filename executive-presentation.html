Section 4 · Why These Choices

Decisions & Trade-offs

Explainability is non-negotiable

Decision Log Highlights

Why These Choices

  • Prebuilt binary install — no Go runtime needed
  • CVSS_V4 > V3 > V2 — newest vector wins
  • Absent CVSS → low — still emits finding
  • Single LF terminator — satisfies wc -l contract

Section 5 · Hand-Off

Reproduce in 3 Commands

Hand-off ready for the next engineer

Onboarding · Run Locally

Three Commands, Zero Surprises

  1. Install: download the OSV-Scanner Linux/amd64 binary from the V2 release page; chmod +x; move onto PATH
  2. Scan: osv-scanner scan source --recursive --format json --output results-osv.json <repo>
  3. Normalize: run the documented Python normalizer to emit findings-config-f.json
