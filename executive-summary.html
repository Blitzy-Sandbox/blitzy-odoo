Tool-Coverage Caveats

What Bandit cannot tell you alone

  • No taint analysis — Bandit is an AST pattern matcher; it does not follow data flow across functions or files.
  • Default ruleset bias — test fixtures dominate hotspots; triage is intentionally out of scope for this baseline.
  • SARIF formatter dependency — install required [sarif] extras; a runtime monkey-patch works around an upstream IndexError.
Compare with taint-tracking SAST Triage in a separate pass Upstream issue tracked

Onboarding & Reproduction

Re-run this scan in four steps

  • Install: pip3 install 'bandit[sarif]'.
  • Save the SARIF wrapper and transformer scripts referenced in decision-log.md.
  • From the repository root: python3 bandit_sarif_wrapper.py -q -r . -f sarif -o results-bandit.sarif.
  • Then: python3 transform_sarif.py results-bandit.sarif findings-config-c.json $(pwd).
