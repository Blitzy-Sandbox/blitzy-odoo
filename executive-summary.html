FOUR DIRECTIVES · GATED PASS/FAIL

Directive-by-directive execution

EXECUTION RECIPE

Four directives, four gates

# Directive Pass criterion
D1 Install + authenticate the Snyk CLI snyk auth check passes · snyk --version returns non-empty
D2 snyk code test --sarif-file-output=results-snyk-code.sarif . results-snyk-code.sarif produced · valid JSON
D3 snyk test --json . > results-snyk-deps.json results-snyk-deps.json contains a vulnerabilities array
D4 Normalize and merge to the five-field schema wc -l == 1 · valid JSON · all 5 fields present · no description > 200 chars

Each directive is a gate: every pass criterion must hold or the pipeline halts. Stage exit codes and wall-clock durations are recorded in the decision log.
