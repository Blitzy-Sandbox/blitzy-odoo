Operational Posture

Operational choices

ChoiceSelectedRationale
Image tag sonarqube:community (rolling) Latest rules and CWE coverage at run time.
Database Embedded H2 Ephemeral, single-run; no persistence required.
Authentication admin:admin Default Basic Auth; bootstrap path documented if first-login forces a change.
Page size ps=500 API maximum; paginate via &p=n when total exceeds 500.
Teardown finally block Frees port 9000 and disk on every success and failure path.

Every choice is recorded in decisions.md with risks acknowledged.
